# Voice Extension — Ableton Devices Course

Extends the base voice bible at [shared/style/voice.md](../../../shared/style/voice.md). The base rules govern; the additions below apply specifically to walking-podcast scripts about Ableton devices.

## Additional Rules

- No rhetorical questions as section openers. Audio does the work.
- Vary sentence length aggressively. Short sentences after two long ones.
- Name-drop specifically: "Tom Jenkinson, recording as Squarepusher in 1997" not "some producers."
- Audio cue markers: write [DEMO: clip_id] inline in script. Build pipeline replaces with audio.
- History sections read like documentary narration. Past tense, present stakes.
- Technical explanations use physical analogy before DSP formula.
- TTS character: knowledgeable, slightly sardonic, unhurried. Authority through precision, not enthusiasm.
