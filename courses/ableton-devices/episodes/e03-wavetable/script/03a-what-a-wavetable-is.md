A wavetable is an ordered collection of single-cycle waveforms. Call each one a frame. The crucial constraint is that every frame in a table shares the same base period — the same length. So the read-pointer that sets pitch advances through whichever frame you're on at a rate set by the note. The position pointer selects which frame you read. Two pointers, two jobs. Move Position and you change only the harmonic content. The pitch does not move, because the period never changed.
