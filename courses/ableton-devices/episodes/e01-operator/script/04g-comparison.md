One honest aside before we build, because Operator is not the only FM tool you'll reach for. If you need a true six-operator architecture — arbitrary routings, DX7 sysex loaded one-to-one, Eno's *Glide* recalled as a binary file — that's FM8 or Dexed, with Plogue OPS7 and Arturia DX7 V for hardware-exact emulation. Everything else — native Live integration, clip envelopes, MPE in Live twelve, the modulation system, the lowest CPU of the bunch — is Operator.

[pause 400ms]

For most IDM percussion, basses, and bell tones, Operator is the right machine. So let's stop comparing and go make one.
