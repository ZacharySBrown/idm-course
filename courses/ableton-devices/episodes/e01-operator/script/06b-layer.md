Now layer it. Add a second Operator instance on a parallel track. Same architecture — but B's Coarse is thirteen, and B's envelope is set to *Beat* at one-eighth dotted.

[pause 400ms]

Hold the same MIDI note across both tracks.

[pause 800ms]

Polyrhythm, emerging from a single held note. Sixteenth grid against dotted-eighth grid. Eleven-to-one inharmonic against thirteen-to-one inharmonic. The two patches are not synced to each other — they are synced to the master clock. The phasing between them is a function of how their envelope cycles align over time.

[pause 500ms]

This is why Autechre stopped making melodies and started making textures. Sean Booth, in the watmm AMA in twenty-thirteen: *"the line between sequencing and synthesis is pretty much gone now. textures are sequences, sequences are like harmonies. it's all the same thing when you get down to it."*

[pause 400ms]

Once your synth *is* the rhythm, the line dissolves. Operator's loop modes are the cheapest way to get there in any contemporary DAW.
