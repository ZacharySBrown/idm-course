Here is the move that should not work, and does. Adding randomness to a stretch makes it *smoother*. Not noisier. Smoother.

[pause 400ms]

Start with the meme, because everyone knows it and almost nobody knows why it sounds that way. August twenty-ten: a producer called Shamantis stretched Justin Bieber's *U Smile* to about thirty-five minutes using a tool called PaulStretch — written by Paul Nasca. The bubblegum pop turned, in NPR's words, "surprisingly like ambient space music." And to prove there was no trick, Jace Clayton — DJ /rupture — sped it back up eight hundred percent and the original Bieber walked right back out.

[pause 500ms]

So what makes PaulStretch sound like a cathedral instead of a metallic loop. Nasca's own description: it is "based on the phase vocoder, but instead of propagating phase information, the algorithm randomizes all STFT phases, resulting in a smoother sound with less repetition and distortion." Here is why that helps. At an extreme stretch, deterministic phase propagation makes the same short window repeat for a very long time — and a repeating window is a periodic tone, an audible metallic buzz at the frame rate. Randomize the phase and you decorrelate one grain from the next. The repetition has nothing to lock onto, so you get a stationary cloud instead. Gabor's quanta scattered, not stacked.

[pause 500ms]

Texture's Flux is the in-Ableton, granular-domain version of the same idea. The manual only says Flux "introduces randomness into how the sample is processed; higher values result in more random variation." It does not say phase randomization in so many words — so the equivalence to PaulStretch's trick is a well-supported inference, not something Ableton confirms. Flag it as that. But listen to what it does.

This is a held note in Texture. Flux at zero — you will hear the periodic buzz we just built. Then I push Flux to a hundred.
