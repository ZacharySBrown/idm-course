Meld has an MPE tab, and it exposes per-note Pitch Bend, per-note Slide on the Y axis, and per-note Press as matrix sources. The crucial fact is that the matrix runs per-voice. So the same patch makes a *different* timbre on every note you're holding, because each finger drives its own copy of the modulation. That's the thing no other Live synth does the way Meld does it — Ableton built it MPE-first.

Two notes, one patch, and only the expressed one brightened and morphed — the still one didn't move. That's per-voice modulation. Each finger shapes its own note's sound.
