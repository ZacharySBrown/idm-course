Six oscillator types in Meld are scale-aware. They're marked with a flat-sharp symbol in the device: Dual Basic Shapes, Chip, and the four swarms — Sine, Triangle, Saw, Square. On these types, partials that would otherwise land on arbitrary inharmonic pitches get snapped to the current Live Scale instead. A wide detuned swarm that would normally smear out of key stays musical. Kleine doesn't treat this as a gimmick — quote, even if you don't use scale awareness, this is a feature that I think is a must-have for any modern synth.
